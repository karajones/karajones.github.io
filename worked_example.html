Adding stats: quantiles?

We need a way to summarize the data to understand if there are differences between groups
Add quantiles to violin plots using quantile.linetype = 1
…but quantile.color = "black" isn’t black 😢

tortoise_body_condition_cleaned |>
  ggplot() +
  # AESTHETICS ----
  aes(
    x = locality,
    y = mean_bci, 
    fill = sex,
    color = sex,
    shape = sex
  ) +
  # GEOMS ----
  geom_violin(
    alpha = 0.3,
    color = NA,
    width = 0.8,
    position = position_dodge(width = 0.8),
    quantile.linetype = 1, # turn on quantiles
    quantiles = c(0.25, 0.5, 0.75),
    quantile.linewidth = 1,
    quantile.color = "black" # not black
  ) +
  ggbeeswarm::geom_quasirandom(
    dodge.width = 0.8,
    alpha = 0.8
  ) +
  # ignore this theme
  large_font_theme()
